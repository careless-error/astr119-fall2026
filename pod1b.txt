❯ why argv?                                                                     

⏺ The name comes from the C language, which Python borrowed it from. It stands
  for "argument vector":

  - arg: the arguments, meaning the words you type after the program name (2.0
    here)
  - v: vector, an old word for a list or array

  So argv just means "the list of command-line arguments."

  Why use it here: it's the standard way, built into Python, for a script to
  read what you typed on the command line. When you run python cometlife.py 2.0,
  the operating system passes cometlife.py and 2.0 to Python, and Python puts
  them in sys.argv. Anything else that reads command-line arguments, like
  argparse, gets them from sys.argv too. For one number, using sys.argv directly
  is the simplest option.

  Compare it with what your module-1 file does now:
  - input(...): the program starts, pauses, and waits for you to type the
    radius.
  - sys.argv[1]: you give the radius when you start the program, and it never
    pauses.

  A quick question to check this: if you ran python cometlife.py 2.0 0.04, what
  would sys.argv[2] be?

  module-2/cometlife.py?
