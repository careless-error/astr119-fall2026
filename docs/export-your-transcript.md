# Exporting your Claude Code transcript

Every homework from HW2 on is submitted with the transcript of the session in which you worked on it.

**In the terminal.** With the session open, type

```
/export hw2-transcript.txt
```

and Claude Code writes the whole conversation to that file in your current folder. Upload it with your homework. If you worked in more than one session, export each one and upload them all.

**Starting fresh.** Open a new session for each assignment (`/clear` or a new terminal) so the transcript covers one piece of work. Name the file after the assignment.

**What we read it for.** How you worked: whether you predicted before running, asked a "why", and caught what the agent got wrong. We do not read it to accuse you of anything. A transcript that shows an agent mistake and how you found it is the best kind.
